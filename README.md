# Liturgia de Hoje

Projeto estático em HTML/CSS/JavaScript, pronto para publicação no Vercel.

## Publicar no Vercel
1. Crie uma conta no Vercel.
2. Crie um novo projeto.
3. Importe esta pasta (ou, preferencialmente, um repositório GitHub com estes arquivos).
4. Framework Preset: Other.
5. Build Command: deixe vazio.
6. Output Directory: deixe vazio.
7. Deploy.
